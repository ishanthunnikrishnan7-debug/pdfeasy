opensourceproject:pdfeasy . com
Merge, split, convert, scan and create PDF documents, right in your browser.
Live site: https://ishanthunnikrishnan7-debug.github.io/pdfeasy/

*FEATURES*:

*Merge*: combine several PDFs into one and set their order.
*Split*: extract chosen pages (for example 1-3, 5, 8-10) or split a PDF into single pages (ZIP).
*Convert*: PDF to JPG, and JPG/PNG/WebP images to PDF.
*Scan*: photograph a page, mark its four corners, straighten it and save a clean PDF.
*Create a PDF*: write on A4 sheets with fonts, sizes, and colors; add images (move, crop, resize); add PDF pages; then save everything as one PDF.
*Note*:All processing happens in your own browser. Your files are never uploaded to a server.
*Note*:Built with plain HTML, CSS and JavaScript in a single file, plus the available open-source libraries.
